# Book CRUD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add MySQL persistence and a tested REST API for creating, reading, updating, searching, and logically deleting books.

**Architecture:** `BookController` handles HTTP, `BookService` enforces business rules, `BookMapper` executes explicit MyBatis SQL, and MySQL stores the `book` table. DTOs and response objects stay separate from the persistence entity.

**Tech Stack:** Java 21, Spring Boot 4.1.0, MyBatis Spring Boot Starter 4.0.x, MySQL 8.0, JUnit 5, Mockito, MockMvc.

## Global Constraints

- Use Java 21, Spring Boot 4.1.0, MySQL 8.0, and MyBatis; do not use JPA, MyBatis-Plus, or Lombok.
- Every normal query filters `deleted = 0`.
- `isbn` is non-null and unique.
- `available_stock` remains between 0 and `total_stock`.
- PP hand-writes the schema, SQL, Service rules, and first tests; AI assists with explanation, review, and repetitive configuration.
- Do not add borrowing, readers, security, Redis, or frontend work in this milestone.

### Task 2: Hand-write and execute the MySQL schema

**Interfaces:** Consumes local MySQL 8.0. Produces database `library_manager` and table `book`.

- [ ] Create the database manually:

```sql
CREATE DATABASE IF NOT EXISTS library_manager CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

- [ ] Create `db/schema.sql` with:

```sql
USE library_manager;
CREATE TABLE IF NOT EXISTS book (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    isbn VARCHAR(20) NOT NULL,
    title VARCHAR(200) NOT NULL,
    author VARCHAR(100) NOT NULL,
    publisher VARCHAR(200),
    total_stock INT NOT NULL,
    available_stock INT NOT NULL,
    deleted TINYINT NOT NULL DEFAULT 0,
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL,
    CONSTRAINT uk_book_isbn UNIQUE (isbn),
    CONSTRAINT ck_book_total_stock CHECK (total_stock >= 0),
    CONSTRAINT ck_book_available_stock CHECK (available_stock >= 0 AND available_stock <= total_stock)
);
CREATE INDEX idx_book_title_deleted ON book (title, deleted);
```

- [ ] Optionally create `db/data.sql` with fake sample books only.
- [ ] Run `DESCRIBE book` and `SHOW INDEX FROM book`; verify ten columns, primary key, and unique ISBN index.
